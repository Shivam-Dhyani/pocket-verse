## Fix: client-side navigations crashing (stuck after sign-in)

- **What:** Fixed a crash on every client-side page change, which manifested as the app
  freezing after a session expired → sign-in (the URL changed to `/login` but the drive's
  "Taking you to sign in…" screen stayed up; only a manual refresh recovered).
- **Root cause:** The theme code removed the React-rendered `<meta name="theme-color">`
  and inserted its own. On the next client-side navigation React tried to remove the tag
  it had rendered, which was gone, and threw `Cannot read properties of null (reading
'removeChild')`.
- **Fix:** The `theme-color` tag is now created and owned only by the pre-paint script
  (`#pv-theme-color`, no `viewport.themeColor`) and updated in place — React never owns
  it. Sign-in and registration also clear the query cache so nothing from a previous
  session carries over.
- **Areas:** `apps/web` `lib/theme.ts`, `layout.tsx`, providers, login/register pages;
  `docs/PWA.md`.
