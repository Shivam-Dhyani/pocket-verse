  refresh tokens, and hard log redaction.
- **Areas:** `apps/api/src/lib/crypto`, auth module, `apps/api/src/lib/logger.ts`,
  `packages/shared`.
- **Verification:** crypto, jwt, logger-redaction, and auth API test suites.

## Phase 2 — storage connection

- **What:** MTProto user client (GramJS) behind a `TelegramGateway` interface; phone →
  OTP → optional 2FA login that creates a private "Pocketverse Storage" channel.
  Restart-safe multi-step login (encrypted state blob in Postgres, 10-min TTL),
  per-connection envelope-encrypted session strings, FLOOD_WAIT handling, per-user mutex.
- **Areas:** `apps/api/src/lib/telegram/`, connection module.
- **Decision:** [ADR-0001](../docs/adr/0001-session-key-encryption.md) — server-side
  master keyring for sessions; password-derived keys deferred to a v2 opt-in.
